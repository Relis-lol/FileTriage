# Contributing

Bug reports and feature suggestions are welcome through GitHub Issues. Please report security vulnerabilities privately as described in [SECURITY.md](SECURITY.md).

FileTriage is dual-licensed for noncommercial and commercial use. Code contributions and pull requests are therefore currently accepted only by prior written arrangement. Please contact [kontakt@saveroq.com](mailto:kontakt@saveroq.com) before writing or submitting code.

Do not expect a pull request to be merged without a suitable written contributor agreement. Opening an issue or pull request does not by itself grant the project the rights needed for commercial relicensing.
