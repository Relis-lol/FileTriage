# Privacy

FileTriage processes file metadata and performs requested file operations locally on the Windows computer where it runs.

- No telemetry or analytics.
- No FileTriage account.
- No cloud upload.
- No FileTriage server calls.
- No network connection is required for the Community build.

The local index contains paths, names, sizes, timestamps, categories, action history, settings, rules, and hashes calculated for duplicate detection. It does not store file contents. Previews are generated locally in memory. Local rotating logs may contain paths and error messages, but not file contents.

GitHub and download platforms process platform and download data under their own privacy terms; that processing is not performed by the FileTriage application.
